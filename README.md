## 기능

### 메모 `v1.0`
- 카테고리별 메모 작성 및 관리
- 마지막 수정 기준 자동 정렬
- 카테고리 생성 / 삭제 / 접기
- 패널 실시간 업데이트

### 일정 관리 `v1.1`
- 시간대별 타임라인 (0–23시, 절대 좌표 배치)
- 자정 넘는 일정 — 다음 날 자동 반영
- 일정 충돌 감지 — 저장 시 경고 + 타임라인 강조
- ID 기반 색상 자동 지정 (새로고침해도 동일)
- 날짜별 컨텍스트 패널 (오늘 / 이번 주 / 다음 주 / 이후)

### 가계부 `v1.2`
- 자연어 입력 → AI 자동 파싱 (Claude Haiku)
- 파싱 후 확인 카드 — 저장 전 수정 가능
- 수동 입력 폼 병행 지원
- 클릭으로 거래 편집 / 삭제
- 월별 수입 / 지출 / 잔액 요약
- 카테고리별 지출 통계
- AI 소비 패턴 분석
